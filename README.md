# Mark2-Calculadora

Calculadora desktop desenvolvida em Python com interface gráfica usando Tkinter.

## ✨ Funcionalidades

- Operações básicas: adição, subtração, multiplicação e divisão
- Operador de porcentagem (`%`)
- Suporte a números decimais (`.`)
- Botão de limpeza total (`C`)
- Tratamento de erro para expressões inválidas

Mark2-Calculadora/

## 🚀 Como executar

### Pré-requisitos

- Python 3.8 ou superior
- Tkinter (normalmente já incluído na instalação padrão do Python)

### Passos

1. Clone o repositório:

	```bash
	git clone git@github.com:GiordanoBruno-dev/Mark2-Calculadora.git
	```

2. Acesse a pasta do projeto:

	```bash
	cd Mark2-Calculadora
	```

3. Execute a aplicação:

	```bash
	python Calculadora.py
	```
